# Preprocessing scripts (raw data → analysis-ready inputs)

These Python scripts document how three of the analysis-ready CSVs in `../data/`
are constructed from their raw sources. They are provided for **transparency**:
the Stata pipeline in `../code/` reads the already-built CSVs, so you do **not**
need to run these to reproduce the paper. Run them only if you want to rebuild
an input from scratch (and, for temperature and latency, only after obtaining
the large raw files, which are not redistributed in this package — see the
Data Availability Statement in `../README.md`).

All scripts resolve paths relative to their own location, so they can be run
from anywhere:

```bash
python preprocessing/process_temperature.py
python preprocessing/process_latency.py
python preprocessing/predict_construction_costs.py
```

| Script | Builds | Raw input(s) | In package? |
|--------|--------|--------------|-------------|
| `process_temperature.py` | `data/country_temperatures.csv` | ERA5 2-m temperature, NetCDF (`data/raw/climate/era5_2m_temperature_monthly.nc`, ~110 MB) + Natural Earth 110m boundaries (downloaded at runtime) | raw `.nc` **not** shipped (size); output CSV **is** shipped |
| `process_latency.py` | `data/country_pair_latency.csv` | WonderNetwork server directory (`data/wondernetwork_servers.csv`) + raw pings (`data/raw/latency/wondernetwork_pings.csv.gz`, ~49 MB) | server file shipped; raw pings **not** shipped (size/terms); output CSV **is** shipped |
| `predict_construction_costs.py` | `data/predicted_construction_costs.csv` | `data/dcci_2025_construction_costs.csv` + World Bank WDI files (`wb_*_2023.csv`, `wb_country_regions.csv`) + `data/seismic_zones.csv` | all inputs shipped; runs end-to-end and reproduces the shipped CSV byte-for-byte |

## Determinism

`predict_construction_costs.py` is fully deterministic and regenerates the
shipped `predicted_construction_costs.csv` exactly. `process_temperature.py` and
`process_latency.py` are deterministic given their raw inputs; they are not
runnable inside this package because the two large raw files are not
redistributed (place them at the paths above to rebuild).

## A note on `country_electricity_prices.csv`

This input is **not** generated by a single script and so is not included here.
It is a merge of three streams (see the Data Availability Statement):
1. **Eurostat** `nrg_pc_205` (European countries) and **EIA** (United States),
   cleaned to a large-industrial, tax-excluded, USD basis; and
2. **manually-compiled** prices for ~20 non-European/non-EIA countries (e.g.
   Kyrgyzstan, Turkmenistan, Canada, China) drawn from GlobalPetrolPrices,
   national regulators/utilities, and the IEA. The per-row provenance is
   recorded in the file's own `source` column (rows tagged `research`).
The Eurostat+EIA cleaning logic is available as `Programs/process_electricity.py`
in the full project repository; the non-European rows are primary hand-compiled
data and are shipped as `data/raw/electricity/non_european_prices.csv`.

## Dependencies

```
numpy
netCDF4      # process_temperature.py only
geopandas    # process_temperature.py only
shapely      # process_temperature.py only
```

`predict_construction_costs.py` and `process_latency.py` need only `numpy`
(plus the Python standard library). Tested with Python 3.12.
